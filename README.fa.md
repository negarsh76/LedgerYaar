# دفتر یار — LedgerYaar

## نسخهٔ ۱.۲ — ارتقا به AGP 9
- AGP 9.3.0، Gradle 9.5.0، Kotlin 2.4.21، Compose Multiplatform 1.12.0، KSP 2.3.13، Room 2.8.4، Koin 4.2.1، compileSdk 36.
- طبق قانون AGP 9 پروژه دو ماژول شد:
  - `composeApp/` — کد مشترک (رابط کاربری، دیتابیس، منطق) به‌صورت کتابخانهٔ KMP (`com.android.kotlin.multiplatform.library`).
  - `androidApp/` — خود اپ اندروید: `MainActivity`، پیامک‌گیر، نوتیف‌خوان، نوتیف‌ها، آیکون‌ها و Manifest.
- برای اجرا در Android Studio پیکربندی **androidApp** را انتخاب کن (نه composeApp).

## تازه‌های نسخهٔ ۱.۱
- **ثبت خودکار از پیامک بانک**: هر پیامک برداشت/واریز (ملی، ملت، سامان، پاسارگاد، تجارت، … و هر بانکی با قالب مشابه)
  خودش خوانده و ثبت می‌شود. کد: `domain/autoimport/BankMessageParser.kt` (+ تست در `commonTest`).
- **نوتیف اپ‌های بانکی (بلوبانک و …)**: بانک‌های ایران API عمومی برای حساب شخصی ندارند، پس اپ نوتیف خود اپ بانک را
  می‌خواند (`androidMain/.../autoimport/BankNotificationListener.kt`). باید از تنظیمات اپ «نوتیف اپ‌های بانکی» را روشن کنی.
- **نوتیف «بابت چی بود؟»**: بعد از هر تراکنش یک نوتیف می‌آید؛ همان‌جا تایپ می‌کنی (مثلاً «ناهار») یا «درسته» را می‌زنی.
  اپ از اصلاح‌هایت یاد می‌گیرد (مثلاً «اسنپ» ← رفت‌وآمد) و دفعهٔ بعد خودش درست حدس می‌زند.
- **صفحهٔ «بررسی پیامک‌های بانک»** + کارت روی داشبورد؛ خواندن پیامک‌های ۷/۳۰/۹۰ روز گذشته.
- **یادآوری روزانه** قسط/بدهی سررسید و تراکنش‌های بررسی‌نشده (AlarmManager، بدون کتابخانهٔ اضافه).
- **پشتیبان روی ایمیل** و بازیابی از فایل (تنظیمات). جدا از این، `allowBackup` روشن است و اندروید خودش
  داده‌ها را در حساب گوگلِ گوشی هم ذخیره می‌کند.
- **تم جنگلی** 🌿 (تنظیمات ← تم)، آیکون و لوگوی جدید، صفحهٔ لودینگ با عکس جنگل.
- تاریخ سریع (امروز/دیروز/پریروز) در فرم ثبت دستی.

### اولین اجرا روی گوشی
1. اپ موقع اولین باز شدن اجازهٔ پیامک و نوتیف را می‌پرسد → «اجازه».
2. تنظیمات ← «نوتیف اپ‌های بانکی» ← روشن کن (برای بلو لازم است).
3. اگر اندروید گفت «تنظیمات محدود شده»: تنظیمات گوشی ← برنامه‌ها ← دفتر یار ← منوی ⋮ ← «اجازه به تنظیمات محدود»، بعد دوباره.
4. صفحهٔ «بررسی پیامک‌های بانک» ← «۳۰ روز اخیر» تا پیامک‌های قبلی هم وارد شوند.

> روی iOS، اپل اجازهٔ خواندن پیامک/نوتیف برنامه‌های دیگر را نمی‌دهد؛ این بخش فقط روی اندروید فعال است.
> چون اپ اجازهٔ پیامک می‌خواهد، انتشار در گوگل‌پلی محدودیت دارد؛ برای نصب شخصی (APK) مشکلی نیست.

---

نسخه‌ی **Kotlin Multiplatform** اپ «دفتر کل»، دقیقاً با همون معماری پروژه‌ی BirthdayYaar شما:
اندروید + iOS از یک کدبیس مشترک، با Compose Multiplatform، Koin، Room چندسکویی،
و لایه‌ی domain/usecase جدا. این نسخه **کاملاً دوزبانه (فارسی/انگلیسی)** است.

## ساختار پروژه
```
composeApp/
  src/commonMain/kotlin/com/ledgeryaar/
    domain/model/       مدل‌های دامنه + تبدیل‌گر تقویم شمسی (pure Kotlin، بدون java.time)
    domain/usecase/     یک UseCase برای هر عملیات + محاسبات دفتر کل (LedgerData)
    data/db/            Room چندسکویی (Entity/DAO/Database)
    data/repository/    LedgerRepository + SettingsRepository (زبان و تم)
    i18n/                AppStrings دوزبانه (فارسی پیش‌فرض، انگلیسی جایگزین) + LocalStrings
    di/                  ماژول‌های Koin
    ui/theme, ui/components, ui/screens/*, ui/nav
  src/androidMain/       Application، MainActivity، پیاده‌سازی Room و DataStore اندروید
  src/iosMain/           MainViewController، پیاده‌سازی Room (BundledSQLiteDriver) و DataStore iOS
  src/commonTest/        تست واحد تبدیل تقویم و تولید اقساط
iosApp/                  پروژه‌ی Xcode (از همون تمپلیت BirthdayYaar، فقط با شناسه‌ی بسته‌ی جدید)
```

## دوزبانگی
- زبان پیش‌فرض **فارسی** است؛ از صفحه‌ی «تنظیمات» می‌توان به انگلیسی سوییچ کرد.
- با تغییر زبان، جهت کل رابط کاربری هم خودکار بین RTL و LTR عوض می‌شود
  (`LocalLayoutDirection` در `LedgerYaarApp.kt`).
- همه‌ی متن‌های ثابت (عنوان صفحات، دکمه‌ها، پیام خطا و ...) از `i18n/Strings.kt` می‌آیند.
- تاریخ‌ها همیشه با تقویم **شمسی** نمایش داده می‌شوند (چه در حالت فارسی چه انگلیسی)، چون
  این انتخابیه که شما برای اپ‌های قبلی‌تون هم داشتید؛ اگر می‌خواید در حالت انگلیسی
  میلادی نشون داده بشه، در `PersianCalendarConverter` و توابع `displayFull/displayShort`
  می‌شه یک مسیر جایگزین اضافه کرد.

## نحوه‌ی اجرا

### اندروید
1. پروژه‌ی `LedgerYaar` را در Android Studio (Koala یا جدیدتر) باز کنید.
2. صبر کنید Gradle Sync تمام شود.
3. روی Run بزنید (Target: `composeApp`، حداقل API 26).

### iOS
1. یک بار در ترمینال: `cd iosApp && pod install` (نیاز به CocoaPods و Xcode دارد؛ فقط روی macOS ممکن است).
2. `iosApp.xcworkspace` را در Xcode باز کنید (نه `.xcodeproj`، بعد از pod install).
3. Run روی شبیه‌ساز یا دستگاه iOS 16+.

> اگر Xcode پروژه را باز نکرد یا خطای شناسه‌ی build گرفتید، ساده‌ترین راه این است که
> از ویزارد «New Compose Multiplatform Project» در Android Studio یک پروژه‌ی خالی
> بسازید و فقط پوشه‌ی `iosApp` تولیدشده را جایگزین این پوشه کنید — فایل‌های Kotlin
> این پروژه (`commonMain`/`androidMain`/`iosMain`) بدون تغییر کار می‌کنند.

## چیزهایی که عمداً پیاده نشده
مثل نسخه‌ی قبلی، بخش‌های «وبلاگ» و «پنل مدیریت محتوا»ی اپ وب اصلی کنار گذاشته شدند چون
ربطی به هسته‌ی دفترداری مالی نداشتند. اعلان/نوتیفیکیشن (که در BirthdayYaar برای یادآوری
تولد بود) هم برای این اپ اضافه نشده — چون منطقی نداره برای دفتر کل به‌طور پیش‌فرض
نوتیف بفرسته، ولی اگر بخواید (مثلاً یادآوری سررسید قسط)، ساختار
`AndroidNotificationScheduler`/`IosNotificationScheduler` از BirthdayYaar رو می‌شه
عیناً به همین پروژه اضافه کرد.

## آیکون و صفحه‌ی ورود (Splash)
- **آیکون اپ**: طرح «دفتر کل + مهر موم قرمز» با همون پالت رنگی پروژه، هم برای اندروید
  (adaptive icon در `androidMain/res/mipmap-anydpi-v26` + `drawable/ic_launcher_fg.xml`)
  و هم برای iOS (`iosApp/iosApp/Assets.xcassets/AppIcon.appiconset`, تصویر ۱۰۲۴×۱۰۲۴)
  از پیش آماده و متصل شده — نیازی به کار اضافه نیست.
- **صفحه‌ی Splash/Welcome**: موقع باز شدن اپ حدود ۱.۴ ثانیه لوگو (دفتر + مهر، رسم‌شده
  با Compose Canvas — بدون فایل تصویر جداگانه، پس روی اندروید و iOS دقیقاً یکسانه)
  و اسم اپ نمایش داده می‌شه، بعد با محو شدن ملایم می‌ره سراغ داشبورد.
  کد در `ui/screens/splash/SplashScreen.kt` و لوگو در `ui/components/LedgerLogo.kt`.
  این صفحه فقط تزئینیه و نیازی به رمز/حساب کاربری نداره.
